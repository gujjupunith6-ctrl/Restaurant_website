# Restaurant Website

## Project
A simple restaurant webpage created using HTML and CSS.

## Features
- Home section
- About section
- Simple food menu
- Special offer section
- Contact details

## Files
- `index.html` - webpage structure
- `style.css` - webpage design

## How to Run
1. Open this folder.
2. Double-click `index.html`.
3. The webpage opens in your browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `style.css` to the repository.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

Note: The restaurant name, menu, prices and contact details are sample content. Replace them if needed.
